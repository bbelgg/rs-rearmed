# GL/CGL functions libRSOpenGL wraps besides the game's imports (game-gl-imports.txt):
# what the Cg shim, the shell (shims/platform/src/rsp_shell.m), the overlay and the test
# programs call (nm -u). Same format: one _name per line; '#' lines are comments.
# Every gl*/CGL* name a client of libRSOpenGL calls must be listed (or be a game import):
# one that isn't still links, through the re-exported system framework, and on
# RS_GL_BACKEND=metal calls Apple's GL with no context (a crash). The check:
#   nm -u <binary> | grep -E '^_(gl|CGL)[A-Z]'  against the generated gl_api.inc.
# A name that is also a game import is ignored here. tools/gen-gl-api.py appends these to
# the wrapper table after the game's imports; on RS_GL_BACKEND=metal each one, too, goes
# to rsmtl_<name> (a weak "unimplemented" stub unless src/metal/ defines it).
#
